## 🎯 Near-term (v0.8)

| # | Feature | Description | Status |
|---|---------|-------------|--------|
| 1 | **MCP client support** | Connect any [Model Context Protocol](https://modelcontextprotocol.io/) server and instantly gain thousands of tools | 📋 Planned |
| 2 | **Local Whisper STT** | Offline voice input as an alternative to Deepgram | 📋 Planned |
| 3 | **Published Docker image on GHCR** | `docker run ghcr.io/ericwang915/pythonclaw` | 📋 Planned |
| 4 | **Proactive agent** | Wire up the heartbeat loop so the agent can reach out on a schedule / on triggers | 📋 Planned |
| 5 | **One-click deploy templates** | Railway / Fly.io / Render templates | 📋 Planned |
| 6 | **Slack channel** | Add Slack as a messaging channel | 📋 Planned |
| 7 | **Streaming responses on Discord & WhatsApp** | Telegram/Web already stream — extend to all channels | 📋 Planned |
| 8 | **Sub-agent spawning** | Parallel task decomposition via sub-agents | 📋 Planned |
| 9 | **Vision model routing** | Auto-pick a multimodal model when an image is attached | 📋 Planned |
| 10 | **Structured tool-result caching** | Cache tool results across turns for efficiency | 📋 Planned |
